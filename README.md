# Task 3: SQL for Data Analysis

## Objective
To use SQL queries to extract, manipulate, and analyze data from an Ecommerce database.

## Dataset
Brazilian E-Commerce Public Dataset (Olist).

The dataset contains information about customers, orders, payments, reviews, products, and sellers.

## Tools Used
- DB Browser for SQLite
- SQLite
- SQL

## Work Performed

The following SQL concepts and operations were covered:

1. SELECT, WHERE, ORDER BY, and GROUP BY
2. Aggregate Functions (COUNT, SUM, AVG)
3. INNER JOIN, LEFT JOIN, and RIGHT JOIN
4. Subqueries
5. Creating Views for data analysis
6. Indexing and Query Optimization
7. Ecommerce sales and customer analysis

## Database Tables

- customers
- order_dataset
- order_payments
- order_reviews
- orders_items
- products
- sellers

## Deliverables

- SQL query file (`task3_queries.sql`)
- SQLite database (`internship1.db`)
- Screenshots of SQL query outputs

## Conclusion

This project helped me understand SQL fundamentals and advanced concepts through practical Ecommerce data analysis. It improved my ability to retrieve, organize, and analyze structured data using SQL.
